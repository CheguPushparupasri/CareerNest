# CareerNest

**A Full-Stack Student Career Management SaaS Platform**

CareerNest is a platform designed to help students organize and manage their career development activities in one place.

### Technology Stack
- Frontend: React.js, Vite, Tailwind CSS
- Backend: Java 21, Spring Boot
- Database: MySQL
- Security: Spring Security, JWT
- API Documentation: Swagger/OpenAPI

### Key Features
- Authentication and role-based access
- Student dashboard
- Profile management
- Project management
- Resume management
- Certifications tracking
- Learning progress tracking
- Internship application tracking
- Coding practice tracking
- Notifications
- Admin dashboard

### Project Status
Actively under development. Core authentication, security and administrative functionality have been implemented. Student-facing modules and integrations are being progressively completed and tested.
